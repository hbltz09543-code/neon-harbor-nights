Neon Harbor Nights is an original open-world crime game for the browser: explore the sun-soaked city of Port Azura on foot and by car, steal cars, run courier jobs and a six-mission story for fixer Vera Solano, dodge or fight the police wanted system, and pay off Jett Marlowe's debt. It runs offline from static files with keyboard and mouse — no build step, no network, all art drawn and all sound synthesized in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. (`node main.ts` with `MAKEFUN_OUTPUT_DIR` set assembles the competition entry: the game, the screenshots and dossier.json.)
